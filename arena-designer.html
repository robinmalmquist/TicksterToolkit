Basic Work flow
Click 'Create new' to create a new layout. Name it and set a Venue Id. Select working folder (same structure as legacy Layout Editor recommended (e g GXFS/Venue/[VenueId]/Layouts)). Create sections as described in Sections Modal. Save and close when ready. Make adjustments needed using tools. Create price regions and Entry points, and assign seats to them. Entry points are not mandatory, but still recommended. The Price regions panel shows a check icon when all seats are assigned. This is crucial. Once satisfied press Export and export all files. Continue work in Boxy SVG.
Tools
Selection mode
Section (S), Row (D), and Seat (F) decide what a click selects.
Select (C)
Click or box-select seats, rows, or sections.
Move (V)
Drag selected seats to reposition them.
Rotate (R)
Rotate selected seats around the pivot.
Resize (Z)
Scale selected seats using the resize handles. Hold Ctrl while dragging to keep the selection ratio.
Bend (B)
Bend a selected row with an anchor handle. End points are also adjustable. Hold down shift while dragging to bend from row center. Scroll up/down to adjust bend sharpness. Double click handle to reset row.
Reshape row (E)
Right click on a seat in any selected row to set/toggle that row's anchor point, then drag row end points or the anchor itself to reshape while preserving existing bends. With a single anchor, hold Shift while dragging a row end to rotate in 5° steps from the anchor while still adjusting row length. If two anchored rows are selected, dragging one anchored row reshapes all selected rows between them; hold Shift to move both anchored rows together. Press Esc to clear all anchors.
Reset row (Q)
Restore a row to a straight line from first to last seat on selected row.
Make table (T)
Reshapes a row to mimic a table for customers wanting a table grid through the seating function.
Deselect (Ctrl+D)
Clear the current selection.
Update outlines
Recalculate section outlines from seats.
Update RowIds
Renumber SeatId per row so they start at RowId.1.
Price Regions
Using the panel to the right, you can add price regions and set a preferred color to each one of them. Then you simply make a selection and click "Add" in order to add these seats to a specific price region.
Clicking "Select" makes a selection of every seat within that price region.
Clicking "Clear" removes every seat from that specific price region.
Entry Points
In the same way price regions are created and managed, you also manage your Entry Points. Create them in the Entry Points Panel and then add seats to their correct entry point.

Goodness
To set goodness, make a selection, right click on the canvas where the seat with best goodness is and select "Set goodness from point". In the modal you can choose range directly, and click "Add range" to create more ranges (default is three). Lower is better.
Create Sections
Click "Manage sections" and select "+New section" to start creating a new section. Type the section name and use the grid editor to paint seats. Use "Add" to click-drag and fill cells, "Remove" to erase cells, and "Select" to mark full rows. "Draw Free" lets you draw across rows, while "Draw rows" locks drawing to one row at a time. Numbering modes now support per-row start at 1, continuous, continuous zigzag, and center odd/even numbering. Row numbers start at 1 from the top. You can choose if seat numbering compacts after deletions or keeps existing numbers, and if broken rows stay on the same RowId or split into new RowIds.
Import Sections
You can import sections from an Excel file. In the Excel file each tab represents a section and the tab name represents the sections name. Column A is dedicated to row names, and from column B and onwards is where seat names goes. Use "-" to create one or more gaps in a row that keeps the same RowId. Use blank cells to create gaps and continues with a new RowId. You can also add the tabs "Entry" and "PriceRegion" where you can add entry points and price regions. They are all added in column A.
